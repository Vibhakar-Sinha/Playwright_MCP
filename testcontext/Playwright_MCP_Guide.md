# Playwright MCP (Model Context Protocol)

# Role of LLM, Agent & MCP in Playwright Test Automation

AI-powered test automation using Playwright is built on three important components:

- **Large Language Model (LLM)** – Thinks and generates instructions
- **Agent** – Executes tasks automatically
- **Model Context Protocol (MCP)** – Connects AI with real tools like browsers and APIs

Understanding these three components makes it much easier to learn **Playwright MCP**.

---

# 1. Large Language Model (LLM)

A **Large Language Model (LLM)** is an AI model trained on a massive amount of data. It understands human language and generates intelligent responses.

### Examples

- ChatGPT
- Claude
- Gemini
- Deepseek


## What Can an LLM Do?

- Understand natural language (English)
- Read requirements and user stories
- Generate Playwright code
- Create test cases
- Explain automation concepts
- Suggest improvements

### Important

An LLM **cannot perform real actions** such as:

- Opening a browser
- Clicking buttons
- Typing into text boxes
- Executing Playwright tests

It only **generates instructions**.

### Simple Understanding

> **LLM = "What to do"**
>
> Think of it as the **Brain** or **Idea Generator**.

---

# 2. Agent

An **Agent** is an intelligent assistant that takes the instructions generated by an LLM and performs real tasks automatically.

Unlike an LLM, an Agent can interact with applications and systems.

## What Can an Agent Do?

- Execute browser automation
- Read system alerts
- Fetch logs
- Restart services
- Navigate websites
- Call APIs
- Interact with databases
- Complete multi-step workflows

### Important

- Works with little or no human intervention
- Converts ideas into real actions

### Simple Understanding

> **Agent = "How to do it"**
>
> Think of it as the **Executor** or **Doer**.

---

# 3. Model Context Protocol (MCP)

The **Model Context Protocol (MCP)** is the communication layer between AI and external tools.

It acts as a **translator** that allows an Agent to communicate with browsers, APIs, databases, file systems, and many other tools.

## MCP Can Connect To

- Browsers
- APIs
- Databases
- File Systems
- Local Applications

## What Does MCP Do?

- Receives instructions from the Agent
- Converts them into a standard format
- Sends them to the appropriate tool
- Returns the results back to the Agent

### Browser Actions Through MCP

- Click
- Type
- Navigate
- Select options
- Upload files
- Take screenshots

---

# Accessibility Tree

One of the biggest advantages of Playwright MCP is that it uses the **Accessibility Tree** instead of screenshots.

## What is an Accessibility Tree?

An Accessibility Tree is a structured representation of a web page that describes every UI element.

It contains information such as:

- Buttons
- Text fields
- Links
- Checkboxes
- Headings
- Labels

Since MCP works with structured UI information instead of images, automation becomes:

- Faster
- More accurate
- More reliable

---

# Simple Understanding

> **MCP = "Execution Layer / Translator"**

It connects AI with real-world applications.

---

## Benefits of Playwright MCP

- Write tests in plain English
- Less coding required
- AI-assisted automation
- Faster test creation
- Supports self-healing when UI changes
- Easier for beginners

# Installation and Setup

# GitHub Copilot, Playwright & Playwright MCP Server

This section explains how to prepare your system for **AI-powered web automation** using:

- GitHub Copilot
- Playwright
- Playwright MCP Server

---

# Complete Setup Flow

Follow these three main steps:

1. Install GitHub Copilot
2. Install Playwright
3. Install the Playwright MCP Server

After completing the setup, you'll be able to automate browsers using **plain English prompts**.

---

# Step 1: Install GitHub Copilot

## Requirements

- Visual Studio Code
- GitHub Account

> **Note:** GitHub Copilot is available as an extension in VS Code.

---

## Authenticate GitHub Copilot

1. Open Visual Studio Code.
2. Click the **GitHub** icon.
3. Sign in using your GitHub account.
4. Grant the required permissions.

After successful authentication:

- GitHub Copilot becomes active.
- Status changes to **Ready**.

---

## Sign Out from GitHub Copilot

1. Click the **Accounts (Profile)** icon in the bottom-left corner of VS Code.
2. Select your GitHub account.
3. Click **Sign Out**.

---

# Copilot Chat Modes

GitHub Copilot provides three chat modes.

| Mode | Purpose |
|------|----------|
| **Ask** | Ask questions and get explanations |
| **Edit** | Modify or improve existing code |
| **Agent (Recommended)** | Best for AI-powered automation tasks |

> **Recommendation:** Use **Agent Mode** for Playwright MCP automation.

---

# Step 2: Install Playwright

Open the terminal inside your project folder and run:

```bash
npm init playwright@latest
```

> **Important:** This command installs Playwright **inside the current project**. It is **not** a global installation.

During installation, Playwright creates:

- package.json
- playwright.config.ts (or .js)
- tests folder
- node_modules
- Browser binaries

---

## Installation Options

Choose the following during setup:

| Question | Recommended Answer |
|-----------|--------------------|
| Install Playwright? | Yes |
| Language | TypeScript |
| Test Folder | tests |
| GitHub Actions | No (Optional) |
| Install Browsers | Yes |

---

## Browsers Installed

Playwright installs:

- Chromium
- Firefox
- WebKit

---

# Useful Playwright Commands

## Run All Tests

```bash
npx playwright test
```

---

## Run Tests with UI Mode

```bash
npx playwright test --ui
```

---

## Run Only Chromium Tests

```bash
npx playwright test --project=chromium
```

---

# Optional: Playwright Test VS Code Extension

Installing the **Playwright Test** extension provides:

- Run button
- Debug button
- Integrated test explorer

### Benefits

- No need to use the terminal every time
- Easier debugging
- Beginner-friendly experience

# Step 3: Install the Playwright MCP Server

---

# Installation Methods

You can install the Playwright MCP Server in:

- Visual Studio Code (Stable)
- Visual Studio Code Insiders

### Simple Installation

1. Open the official GitHub repository:

```
https://github.com/microsoft/playwright-mcp
```

2. Click **Install Server in VS Code**.

The server will be installed automatically.

---

# Managing the MCP Server

Open the **Command Palette**:

```text
Ctrl + Shift + P
```

Search for:

```text
MCP: List Servers
```

From there, you can:

- Start the server
- Stop the server
- Restart the server
- View server configuration

---

# MCP Configuration File

The MCP Server configuration is stored in:

```text
mcp.json
```

You can customize server settings and commands manually if needed.
